# Кунегунда

Бот-гадалка для бесед ВКонтакте, запускается на Render.

Бот получает сообщения через **Bots Long Poll API** (сам забирает их из ВК), потому что серверы ВК не могут подключиться к Render (Callback API давал ошибку «Can't connect to server»). Раз в 10 минут бот сам открывает свою страницу, чтобы бесплатный Render не засыпал.

## Что умеет
- Команда **гадать** (также `.гадать`, `/гадать`, `гадать!` или с упоминанием бота) — предсказание про Аватарию, максимум 3 в день на человека (лимит хранится в Supabase, таблица `user_limits`).
- Когда бота добавляют в беседу, он представляется.
- Когда в беседу заходит новый участник, Кунегунда здоровается и делает ему бесплатный расклад.
- На остальные сообщения (например, «привет») бот не отвечает: так задумано.

## Render
- Build command: `pip install -r requirements.txt`
- Start command: `gunicorn app:app`
- Environment variables:
  - `VK_GROUP_TOKEN` — ключ доступа сообщества (с правом «сообщения сообщества»)
  - `VK_GROUP_ID` — id сообщества (по умолчанию 241804933)
  - `VK_CONFIRMATION_TOKEN` (только для Callback API, сейчас не обязателен) — строка, которую должен вернуть сервер (из настроек Callback API)
  - `VK_SECRET_KEY` — секретный ключ из настроек Callback API
  - `GROQ_API_KEY`
  - `SUPABASE_URL`, `SUPABASE_KEY`

Токены нельзя писать в код: репозиторий публичный.

## ВКонтакте (Управление сообществом)
1. Сообщения → включить сообщения сообщества.
2. Сообщения → Настройки для бота → включить «Возможности ботов» и «Разрешать добавлять сообщество в беседы».
3. Работа с API → **Long Poll API**: включить, версия 5.199.
4. Long Poll API → Типы событий → включить «Входящее сообщение».
5. В беседе выдать боту права администратора (или доступ ко всей переписке), иначе он видит только сообщения с упоминанием.
